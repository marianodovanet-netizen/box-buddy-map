# Dovanet NAP Tracker

Crear una aplicación web para Dovanet que permita registrar cajas NAP reparadas. Cada registro debe guardar coordenadas GPS, técnico, fecha, localidad, dirección, trabajo realizado, observaciones y fotografías. Mostrar todas las NAP registradas en un mapa interactivo. Habilitar Lovable Cloud para persistir los registros y las fotos; usar Google Maps Platform administrado por Lovable para el mapa, geolocalización y selección de coordenadas.

This project was built with [Lovable](https://lovable.dev).
